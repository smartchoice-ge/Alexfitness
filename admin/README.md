# Admin Panel

This folder contains all the administrative interface files for the Synergy Gym management system.

## Files:

- **index.php** - Admin panel entry point, redirects to login if not authenticated
- **users_list.php** - Main admin dashboard showing client list and management
- **settings.php** - System settings management
- **package_settings.php** - Gym package pricing and configuration management  
- **emails.php** - View and search sent emails
- **payments.php** - Payment history and transaction management
- **client.php** - Individual client detail view and management
- **admin_images.php** - Profile image management system
- **paused_memberships.php** - Manage paused memberships

## Access:

All admin files require authentication. Users must log in through the main login system to access admin functionality.

## Navigation:

The admin navbar is shared across all admin pages and provides navigation between different administrative functions.
